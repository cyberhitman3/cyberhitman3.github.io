## Vulnerability Analysis

### The RRD Graph Injection Vulnerability

**Technical Details:**

- **Vulnerable Component:** `_rrd_graph_img.php`
- **Parameter:** `graph` GET parameter
- **Attack Vector:** Command injection via graph parameter
- **Execution Context:** Root privileges
- **Requirements:** Valid authentication
- **Impact:** Complete system compromise

**Exploitation Mechanism:**

The `graph` parameter in the RRD graph generation page doesn't properly sanitize user input. An authenticated attacker can inject arbitrary shell commands that execute with root privileges through the PHP script's system call.

Example payload structure:

```
graph=processor;whoami;
```

The semicolon allows command chaining, executing arbitrary commands as root.
