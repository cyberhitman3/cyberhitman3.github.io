Summary & Key Takeaways
Attack Chain
Exposed .git directory → Git dumping with git-dumper
Credential discovery → Found MySQL/Backdrop CMS credentials in repository
CMS login → Credential reuse on Backdrop CMS interface
Backdrop RCE → Exploited CVE in Backdrop 1.27.1 via public exploit
Lateral movement → SSH access via password reuse
Privilege escalation → Sudo access to bee CLI utility with PHP eval
Key Vulnerabilities
Exposed .git directory with sensitive credentials
Weak credential reuse across services
Unpatched Backdrop CMS with known RCE vulnerability
Dangerous sudo configuration allowing arbitrary PHP execution
Tools Used
nmap — port scanning
git-dumper — repository extraction
grep — credential hunting
backdrop-rce — automated exploit
ssh — lateral movement
bee — Backdrop CLI exploitation
Lessons Learned
Always check for exposed version control directories (.git, .svn, .hg)
Credential reuse across services is a critical escalation vector
Dangerous CLI utilities with broad sudo privileges can lead to immediate root access
Keeping applications patched is essential — Backdrop 1.27.1 had known vulnerabilities
