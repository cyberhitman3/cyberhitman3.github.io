## Introduction

Paper is an Easy Linux machine from Hack The Box that demonstrates the importance of chaining multiple vulnerabilities together. The attack path includes virtual host discovery, WordPress enumeration, path traversal in a chat bot, credential reuse, source code analysis, and finally a race condition privilege escalation exploit.

The machine initially exposes SSH and HTTP/HTTPS services. Enumeration leads to a WordPress installation hosted on the `office.paper` virtual host. A static WordPress page reveals an internal Rocket.Chat instance.

After registering an account on Rocket.Chat, I discovered a bot named `recyclops` that was vulnerable to path traversal, exposing the Hubot `.env` file containing credentials. These credentials enabled SSH access as `dwight`.

Further analysis of the Hubot source code revealed dangerous command execution functionality, leading to RCE as Dwight. Privilege escalation was achieved through CVE-2021-3560, a Polkit race-condition vulnerability.

### Command Execution via Hubot

Examined the Hubot source code in `/home/dwight/hubot/`. The `run.js` file revealed arbitrary command execution functionality:

```javascript
module.exports = function(robot) {
    robot.respond("/RUN (.*)$/i", function(msg) {
        var cmd = msg.match[1];
        msg.send("Running " + cmd);
        
        var exec = require('child_process').exec;
        exec(cmd, function(error, stdout, stderr) {
            if (error) {
                msg.send(error);
                msg.send(stderr);
            } else {
                msg.send(stdout);
            }
        });
    });
};
```

**Vulnerability:** Attacker-controlled input from `msg.match[1]` was passed directly to `child_process.exec()` without any restrictions. This is a classic example of OS command injection.

### Exploiting the /RUN Command via Rocket.Chat to get SHELL as Dwight - Path2

### Identifying CVE-2021-3560

**Vulnerability Conditions:**

✅ CentOS 8  
✅ Polkit 0.115  
✅ AccountsService installed  
✅ Unprivileged local user (dwight)

CVE-2021-3560 is a **race condition** in Polkit's authorization process that allows unprivileged users to create privileged accounts.

**How it works:**
```bash
Unprivileged User (dwight)
│
▼
AccountsService (create account request)
│
▼
Polkit (authorization check)
│
▼
⚡ RACE CONDITION ⚡
│
▼
Privileged operation succeeds
```

The exploit wins the race by timing the attack to bypass authorization checks.

## Lessons Learned

### 1. Enumeration Methodology

Don't just run tools blindly. Follow this process:
```bash
Operating System
↓
Software Installed
↓
Software Version
↓
Configuration Details
↓
Known Vulnerabilities
↓
Prerequisites Check
↓
Exploit
```

### 2. Automated Tools Are Starting Points

LinPEAS identified many potential issues, but each required manual validation. Not every finding means the machine is exploitable.

### 3. Version Numbers and Patches

The installed package was:

polkit-0.115-6.el8.x86_64


The `-6.el8` suffix represents the CentOS release, not the upstream version. This distinction matters for vulnerability research.

### 4. Race Conditions Require Patience

CVE-2021-3560 failed on the first attempt due to timing. The second attempt succeeded. Race condition exploits often require multiple tries.

**Key insight:** A failed attempt doesn't mean the vulnerability doesn't exist—it might mean you didn't win the race.

### 5. UIDs vs Usernames

A process can have numeric credentials (UID 1005) without a corresponding `/etc/passwd` entry:

```bash
id           # Shows UID 1005
whoami       # "cannot find name for user ID 1005"
getent passwd secnigma  # No result
```

This distinction is critical for understanding Linux security.

### 6. Privilege Comes from Configuration

Being in the `wheel` group doesn't automatically grant root access. The `/etc/sudoers` configuration is what actually grants privilege:

%wheel ALL=(ALL) ALL


### 7. Source Code Review Reveals Vulnerabilities

Examining Hubot's source revealed obvious command injection:

```javascript
exec(msg.match[1], ...)  // Attacker input directly to exec()
```

Blacklist-based protections often fail. The `files.js` blacklist missed path traversal via `..`.

### 8. Credential Reuse

The Hubot `.env` password was reused across multiple accounts:

Rocket.Chat Bot Password → dwight SSH Password


This is a common real-world attack path.

### 9. Small Vulnerabilities Chain Together

Paper demonstrates how several small issues create a complete compromise:

- Virtual host misconfiguration → WordPress discovery
- Draft page exposed → Chat server discovered
- Path traversal in bot → Credentials leaked
- Credential reuse → Shell access
- Source code exposed → Command injection discovered
- Missing hardening → Polkit race condition successful
